💡 locator.and():
page.getByRole('button').and(page.getByText('Fire Strike'))
→ finds the one button that is both a button AND has text "Fire Strike".

locator.or():
page.locator('.spell').or(page.locator('.rune'))
→ finds all elements that are either .spell OR .rune. Count should be 6.
Log LEVEL_PASSED when both checks pass.
