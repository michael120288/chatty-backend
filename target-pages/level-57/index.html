GET /pages/level-57/grimoire.json
The Ancient Grimoire — contains spell data including a spellCount field.
{ "title": "Ancient Grimoire", "spells": ["Fireball", "Teleport", "Invisibility", "Thunder", "Heal"], "spellCount": 5 }
💡 Use Playwright's APIRequestContext — no browser needed!
const request = await chromium.request.newContext();
const res = await request.get('http://localhost:4000/pages/level-57/grimoire.json');
const body = await res.json();
If res.ok() is true and body.spellCount === 5,
log LEVEL_PASSED. Then await request.dispose().
