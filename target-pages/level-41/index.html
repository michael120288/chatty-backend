Intercept the catalogue fetch — modify the response before it renders

Channeling the arcane catalogue...
💡 Use page.route('**/spell-catalogue.json', async route => {
  const response = await route.fetch();
  const data = await response.json();
  data.spells[0].power = 9999;
  await route.fulfill({ json: data });
}) to intercept and modify the response.
